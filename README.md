# 🐺 狼人杀在线笔记

> 本项目是基于 `syhy0612/lrsNotes` 改进的非官方衍生版本。

发言优先的多轮狼人杀记录台：按轮次保存 12 席原始发言，补充公共事件、私有信息和整体备注，并可生成 AI 策略提示词。数据默认仅保存在浏览器本地，用户自行复制提示词到第三方 AI；本项目不调用 AI API。

## 功能

- 多轮发言记录与自动保存
- 未发言、滑水、无遗言等状态标记
- 可编辑的身份、事件和备注模板
- AI 策略提示词生成
- 桌面端与移动端布局
- 沉浸式星空/纯白背景切换
- 狼人杀与“谁是卧底”记录模式
- 笔记导出与重置
